场景＝面向小学生家长的**产品使用说明 /  onboarding 宣讲**。不属于学术科研、专业咨询、党政红色任一垂直领域 → 走**通用设计原则**，由 query 推导：受众是非技术人群 → 亲和、大字号、强图像、低术语。

## 3. 字体系统

气质方向「活力亲和」→ 圆润、可读性高，适合家长群体（其中不少人不熟悉技术、年龄偏大，字号与字腔必须够宽）。

**字体可用性实测**：本环境可加载 `Arial` / `Verdana` / `Trebuchet MS` / `Georgia` / `Tahoma` / `Comic Sans MS`；
`Poppins` / `Nunito` / `Helvetica` / `Noto Sans` / `DejaVu Sans` / `Liberation Sans` **无法加载**（会回退 Sans 并提示 ugly output）。
因此放弃 Poppins/Nunito 方案，改用实测可用且同样「亲和」的组合：

| 层级 | 字号 | 字重 | 行高 | 字体 |
| :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 66px | bold | 1.2 | `Trebuchet MS` |
| 章节大字 | 60px | bold | 1.1 | `Trebuchet MS` |
| 巨型文字锚点（第 11 页） | **72px** | bold | 1.05 | `Trebuchet MS` |
| 页面主标题（A 区） | 34px | bold | 1.3 | `Trebuchet MS` |
| 副标题 / 卡片小标题 | 24–26px | bold | 1.4 | `Trebuchet MS` |
| 正文 | 20–22px | regular | 1.55 | `Verdana` |
| 说明 / 注解 | 17–18px | regular | 1.5 | `Verdana` |
| 页脚 / 页码 | 14px | regular | 1.4 | `Verdana` |

- **仅 2 套字体家族**：`Trebuchet MS`（标题/巨型锚点——圆润亲和）+ `Verdana`（正文——字腔宽、投影清晰）。
- 巨型锚点与正文不同家族 + 不同字重 → 满足。
- 二者均为 Windows/macOS 常见预装字体，交付后在他人电脑上打开不会掉字体。

## 4. 信息密度门禁

- 常规内容页留白 **≤ 35%**；Hero 页允许 40–45%（第 01/05/11/15 页）。
- **容器填充率 ≥ 85%**：卡片内文字 + 图标垂直占用 ≥ 容器高 85%。
- **底栏锚定**：卡片尾部元素（标签条 / 高亮句）用 `marginTop: 'auto'` 钉到底部。
- **横向兄弟卡对齐**：同一行卡片的「标题块 / 正文块 / 尾条」三段 y 坐标必须对齐，差值 > 16px → 返工。
- **焦点留白**：每个视觉锚点周围留 ≥ 40px。
